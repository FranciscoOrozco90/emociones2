GESTIÓN DE LAS EMOCIONES

Autoestima

Tarea: "Anuncio publicitario"

Querido alumnado:

Para trabajar la autoestima vamos a realizar la siguiente tarea: Partiendo de las cualidades positivas de un compañero/a, debemos realizar una presentación (se recomienda la herramienta Genially para realizarla, pero puedes elegir otra) realizando una "venta" de ese compañero/a, con el objetivo de subir la autoestima entre todos/as.

Para ello, se realizará la tarea por parejas y con una duración de una sesión.

Cada pareja deberá realizar dos presentaciones o una conjunta, pero es importante que cada alumno/a haga la "venta" o "anuncio publicitario" de su compañero/a.

Al finalizar esta actividad, observaremos que todos/as tenemos más cualidades positivas de las que consideramos, haciendo crecer la autoestima de forma colectiva.

En la "GUÍA DIDÁCTICA" observarás los criterios de evaluación asociados.
